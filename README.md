# Pulse Check

A live "This or That" icebreaker for a group, played from everyone's phones. The host starts a room and shows a room code (and a QR code). Players join from their own phones, answer each question, and the group sees how everyone lined up. It runs in the browser with nothing to install.

Rooms use free public MQTT relays over the internet, so a live game needs a connection. Test mode and "Play on this device" run entirely offline in the page.

## What is in this repository

| File | What it is |
|---|---|
| `index.html` | The game, as one packaged file. Opening it in a browser starts Pulse Check. |
| `.nojekyll` | Tells GitHub Pages to serve the file as it is. |
| `THIRD-PARTY-NOTICES.md` | Licenses for the open source libraries inside the page: React, ReactDOM, MQTT.js (with ieee754 and @jspm/core inside it) and qrcode-generator. |
| `README.md` | This file. |

The page also inlines a small runtime that turns the game's page template into a working page (`support.js`). It was generated by Claude Design, the tool the game was first built with, and it carries no license header of its own.

`index.html` is a build, not the source: the source lives elsewhere and is not published here. The page asks search engines not to list it (`noindex`).

## How it is updated

A new build is packaged from the source, then copied in with `tools/site.js` (from the source project). The tool checks the file for anything that must not be public and refuses to copy it if it finds a trace. It only copies; it never commits or pushes. The owner commits the new `index.html` and publishes it with a push that the owner approves.
