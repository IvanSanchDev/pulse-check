HOW THIS ROOM WORKS
Relay. {{ relayLine }} The game tries three free public relays in order: broker.emqx.io (EMQX), broker.hivemq.com (HiveMQ), then test.mosquitto.org (Eclipse Mosquitto).
Privacy. Public relays have no password and no encryption at the relay. Anyone who knows the room code can see game traffic, so keep questions low-stakes.
Host device. This tab runs the game. Keep it open and awake. If it closes or sleeps, play pauses for everyone until you reopen the file.
Timing. Every device syncs to this clock, so each player gets the full {{ timerSec }} seconds. Answers still in when time runs out lock automatically.
Players. Everyone uses Pulse Check v18, from the address above or the same file, and joins with the room code. Players can leave at any time; closing the room sends everyone back to the start screen.
Capacity. Built for up to 100 players. Public relays don't guarantee capacity, so run a trial with real devices before a large session.
